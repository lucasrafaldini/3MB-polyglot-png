# Security Policy

## Scope and intent

`3MB-polyglot-png` is an **educational tool** that demonstrates PNG polyglot
files and trailing-data steganography. It is intended for learning about file
formats, for research, and for legitimate uses such as watermarking or
transporting your own data.

Please do **not** use this project to:

- Distribute malware or evade security controls.
- Exfiltrate data you are not authorized to access or share.
- Violate the terms of service of any platform.

You are responsible for complying with all applicable laws and the terms of any
service you upload polyglot files to.

## Reporting a vulnerability

If you discover a security issue in the tool itself (for example, a parsing bug
that could crash or be exploited when processing a malicious PNG), please report
it responsibly:

1. **Do not** open a public issue for a sensitive vulnerability.
2. Use GitHub's
   [private vulnerability reporting](https://github.com/lucasrafaldini/3MB-polyglot-png/security/advisories/new)
   if enabled, or contact the maintainer directly.
3. Include a description, reproduction steps, and the impact.

We aim to acknowledge reports within a reasonable timeframe and will credit
reporters who wish to be named once a fix is released.

## Supported versions

The latest release on the default branch is the only supported version.
